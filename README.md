# LUNETRAS_DATASET
Projeto de pesquisa para desenvolvimento de um sistema de Inteligência
Artificial capaz de auxiliar na identificação do nível psicogenético
da escrita infantil a partir de produções escritas.

## Objetivo

Desenvolver e avaliar modelos de aprendizado de máquina capazes de
classificar produções escritas infantis segundo níveis psicogenéticos
da aquisição da escrita.

## Classes

- Pré-silábico
- Silábico
- Silábico-alfabético
- Alfabético

## Estrutura

- data/: dados do projeto
- src/: código fonte
- notebooks/: experimentos
- models/: modelos treinados
- reports/: resultados
- docs/: documentação
- tests/: testes
